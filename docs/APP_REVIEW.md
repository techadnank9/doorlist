# App Review notes

Paste the section below into App Store Connect > the version > App Review Information > Notes.
Leave "Sign-in required" ticked and the user name and password fields empty.

---

Doorlist signs in only with Sign in with Apple, so no demo account or password is needed: please use your own Apple ID on the first screen.

What to try:

1. Find tab: type "free tech meetup this week". Doorlist searches public event sites near you and shows matches. Free events can be booked for you; paid events are never booked or paid for, they open on the event's own page instead.
2. Events tab: paste any public event link, for example a luma.com or partiful.com event, and tap the arrow. Doorlist opens the event's own page and fills the sign-up form with answers you have saved. Any new question is asked once, by typing or by voice.
3. Answers tab: every saved answer can be edited or removed. "Delete account" at the bottom of this tab erases the account and everything stored with it.
4. Share extension: in Safari, open an event page, tap Share, then Doorlist.

Signing in to an event site (Luma, Partiful, Eventbrite) is optional, and those logins stay on the device.

Location is used only as a town, to search nearby; you can type a city instead. Calendar access is optional and read on the device only, to skip events that clash.
